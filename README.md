## 🚀 How to Deploy on Vercel

### Option 1: Vercel CLI (Fastest)
1. Open terminal in this folder:
   ```bash
   cd "Website-Portfolio-Glenard"
   ```
2. Run:
   ```bash
   npx vercel
   ```
3. Follow the CLI prompts (accept defaults). Once deployed, Vercel gives you your public link (e.g., `https://website-portfolio-glenard.vercel.app`).

### Option 2: Vercel Dashboard (GitHub Import)
1. Push this repository to GitHub.
2. In [vercel.com](https://vercel.com), click **Add New** > **Project**.
3. Select your repository.
4. Under **Root Directory**, click **Edit** and select `Website-Portfolio-Glenard`.
5. Click **Deploy**.
